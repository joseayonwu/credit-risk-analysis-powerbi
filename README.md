# Credit Risk Analysis — Power BI & Python Integration  
*Interactive dashboard combining data modeling, DAX, and machine learning for credit risk assessment.*

---

## Overview  

This project presents an **interactive Power BI dashboard** analyzing credit default behavior for over **30,000 customers** from the **UCI Credit Card Default dataset**.  
It integrates **Python (PCA and K-Means Clustering)** within Power BI to generate **AI-driven insights** and behavioral segmentation, supporting **data-driven credit policy and portfolio management**.  

Developed as part of the *Master of Data Analytics* program at the **University of Niagara Falls, Canada**, it demonstrates the ability to combine **business intelligence, predictive analytics, and storytelling** for executive decision-making.

## 2. Dashboard Pages  

1. **Overview** – High-level KPIs and credit behavior metrics (Default Rate, MoM Growth).  
2. **Comparative Analysis** – Defaulters vs non-defaulters by demographics and payment patterns.  
3. **Risk & Behavioral Profiles** – Segmentation by gender, education, and marital status.  
4. **Advanced Risk Analysis** – Correlation between credit limit, delinquency, and repayment patterns.  
5. **AI-Driven Insights (Python)** – PCA and K-Means clustering identifying four behavioral groups.

## 4. Key Insights  

- Overall **default rate: 22.1%**, highest among customers aged 60+.  
- **Healthy Use Ratio (0.5–1.0)** group shows lowest default risk (15.7%).  
- **Higher education levels correlate** with lower default probability.  
- **Cluster 3** (identified via K-Means) has the **highest default probability (0.56)**.  
- Integrating **Python with Power BI** enables explainable AI segmentation and better financial risk control.
